ALAS Browser Data Deletion

Last updated: August 1, 2026

Account deletion

ALAS Browser does not currently require users to create an ALAS Browser account. If a future version adds account-based sync, users may request deletion of their account and associated sync data by emailing alaswebsun@gmail.com from the email address associated with the account.

Local browser data

You can delete local browser data directly in the app by opening Settings and using the Privacy controls to clear browsing history, cookies, cache, site storage, downloads, and other local browser data. You can also delete all local app data from Android Settings > Apps > ALAS Browser > Storage > Clear storage.

Optional Sync & Backup data

If you configured Sync & Backup, delete the backup from the server you configured. If the sync server is operated by ALAS Browser, email alaswebsun@gmail.com and include your sync user ID so we can delete the associated backup data.

Data retained

We may retain limited records only when required for legal, security, or abuse-prevention reasons. Local browser data deleted from your device is not recoverable by ALAS Browser.
