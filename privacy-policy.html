1. App Architecture & Privacy Core

ALAS Browser is built from the ground up as a high-performance, private, lightweight Android web browser. We believe that your web browsing activity, search queries, bookmarks, and preferences belong exclusively to you.

Core Guarantee: ALAS Browser does NOT operate central servers to track user activity, does NOT collect diagnostic device telemetry, and does NOT sell or monetize personal user data.

🔒 Zero Remote Tracking

No analytics SDKs, no behavioral fingerprinting, and no background reporting.

⚡ R8 Build Optimized

Compiled with advanced R8 minification, dead-code elimination, and resource shrinking.

🕵️ Isolated Incognito Process

Separate process sandbox for private browsing that leaves zero trace on your device.

🛡️ Built-in Ad Blocker

Host-based ad/tracker blocking with custom element picking and URL filter rules.

2. Zero Telemetry & Metrics Opt-Out

Unlike standard browsers that automatically transmit metrics back to analytics backends, ALAS Browser explicitly disables system and component telemetry:

  • WebView Metrics Opt-Out: The system application manifest explicitly defines android.webkit.WebView.MetricsOptOut = true, ensuring Google Android WebView engine metrics are disabled.
  • No Diagnostic Tracking: ALAS Browser contains no Firebase Analytics, Google Analytics, or third-party telemetry frameworks.

3. Local Data Storage & Isolated Incognito

3.1 Persistent Local Data

To provide standard browsing capabilities, the following data is saved locally on your Android device in app-private storage:

  • Browsing history, open tab states, bookmarks, and quick links.
  • App display preferences, custom search engine configurations, and homepage settings.
  • Web cookies, HTTP cache, and HTML5 localStorage created by websites you visit.
  • Downloaded files and custom ad-blocking rules.

3.2 Dedicated Incognito Sandbox

ALAS Browser features a dedicated Incognito Activity (IncognitoBrowserActivity) running in a separate isolated process (:incognito). Browsing sessions in Incognito Mode do not record history, do not save persistent cookies, and wipe transient cache immediately upon closing the tab session.

4. Build Security, R8 & Log Stripping

This release build of ALAS Browser incorporates rigorous security and compilation optimizations:

  • R8 Code & Resource Shrinking: Full R8 minification (`isMinifyEnabled = true`) and resource shrinking (`isShrinkResources = true`) strip dead code, unused drawables, and extraneous layouts, minimizing binary surface area.
  • Production Log Stripping: All verbose, debug, info, and warning log statements (Log.v, Log.d, Log.i, Log.w) are stripped during compilation. Production releases emit no system logcat traces containing internal state or URLs.
  • Protected Web Interfaces: Reflective JavaScript bridge methods are explicitly protected via @JavascriptInterface rules to preserve secure web-to-app interactions without exposing unintended internal APIs.

5. Ad Blocking & Custom Filter Rules

ALAS Browser includes an integrated host-level and element-level ad blocker designed to protect your privacy and speed up web rendering:

  • Filters known tracking domains, ad scripts, and pop-ups locally before requests are executed.
  • Includes an element picker interface allowing users to select and hide unwanted web elements on any web page.
  • All filter matching is executed locally on your device without sending URL queries to external servers.

6. Device Permissions & Transparency

ALAS Browser requests Android system permissions strictly to deliver user-requested features. The application operates smoothly even if non-essential permissions are denied:

Permission Purpose & Usage Requirement
INTERNET Enables web page navigation, web requests, and asset downloading. Required for Browsing
CAMERA Used by the built-in QR Code Scanner (CameraX) or for web file upload inputs when initiated by the user. Optional (On-Demand)
POST_NOTIFICATIONS Displays active download notifications and background file transfer status on Android 13+. Optional (On-Demand)
ACCESS_FINE_LOCATION Allows web pages to request your location (only if you explicitly grant permission per website prompt). Optional (On-Demand)
RECORD_AUDIO Enables HTML5 WebRTC audio or microphone inputs when requested by a website and approved by the user. Optional (On-Demand)

7. Data Retention & Backup Control

You maintain 100% control over all data generated during your browsing sessions:

  • Disabled Automatic Cloud Backup: allowBackup="false" is explicitly enforced in the application configuration to prevent automatic cloud backup of local browser history, cookies, or saved credentials to external cloud services.
  • On-Demand Clearing: You can clear history, cookies, web storage, and cache at any time through the app settings or via Android App Settings > Clear Storage.
